# JK Editor

Free browser-based photo/design editor for GitHub Pages.

## Deploy on GitHub
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you the live website URL.

The editor uses Fabric.js from jsDelivr CDN, so an internet connection is required for the editor library.
